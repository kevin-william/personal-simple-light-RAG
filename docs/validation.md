Ambiente observado: Windows, Python 3.12.6, NVIDIA GeForce RTX 3050 Laptop
6 GB, driver 617.14. Instalação e teste neste computador não equivalem a
uma instalação em Windows limpo.

requisitos mínimos sem benchmarks. Gates externos permanecem pendentes
até que haja evidência; testes simulados não comprovam qualidade da LLM.
